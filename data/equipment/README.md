## 数据结构

```json
{
  "version": 1,
  "source": "https://wiki.d.163.com",
  "generated_at": "2026-08-13 ...",
  "total_types": 30,
  "total_items": 527,
  "equipment": [
    {
      "category": "武器",          // 武器/职业专用武器/防具/职业专用防具/其他
      "type": "斧头",              // 中文类型名
      "type_en": "Axes",           // 英文类型名
      "source": "https://...",     // 来源页面 URL
      "items": [
        {
          "name": "手斧",          // 中文名
          "name_en": "Hand Axe",   // 英文名
          "tier": "普通",          // 普通/扩展/精华/未分级
          "image": "https://...",  // 图片 URL（外链）
          "attributes": {          // 装备属性
            "单手伤害": "3-6",
            "范围": "1",
            "耐久度": "28",
            "品质等级": "3"
          },
          "set_item": null,        // 所属套装（可空）
          "unique_item": "牙齿"    // 对应暗金装备（可空）
        }
      ]
    }
  ]
}
```

## 重新抓取

```bash
# 全量重新抓取（30 个类型，约 1-2 分钟）
python3 scripts/scrape_equipment.py

# 只抓取指定类型
python3 scripts/scrape_equipment.py Belts

# 列出所有装备类型
python3 scripts/scrape_equipment.py --list
```

> 注意：网站有反爬限流，脚本已内置重试机制和限速。全量抓取请耐心等待。

## 已知说明

1. **图片为外链**：图片 URL 指向 `wiki.d.163.com`，如需本地化请另行下载。
2. **头饰（Circlets）**：仅 4 种基础装备（头饰/宝冠/三重冠/权冠），无普通/扩展/精华分级。
3. **护身符（Charms）**：页面为文字介绍，手动补充了 3 种基础形式（小型/大型/超大型）。
4. **戒指/项链**：数据为暗金首饰列表（无基础装备分级）。
5. **"品质等级需要等级"粘连**：部分防具的属性中该字段在 wiki 源数据中粘连，保留原文。
